Catálogo del generador

88 entradas conservadas del prototipo: 73 mágicas y 15 de equipo. Rarezas cotejadas con el Markdown SRD aportado cuando hay coincidencia exacta; las variantes ambiguas están marcadas. Descripciones y valores pendientes de cotejo; no es todavía el compendio completo del SRD. Tus cambios quedan marcados como homebrew.

Desmarcá «Disponible en loot» para excluir un objeto. Los resultados guardados conservan la ficha que tenían al generarse. La ficha original y las notas homebrew se muestran por separado.

Reglas homebrew y precios

El precio homebrew activo se usa como costo del objeto. La descripción y el valor base originales se conservan. Una regla de objeto tiene prioridad sobre una de categoría.

Las reglas y su activación se guardan en este navegador. Podés pausarlas con el botón sin borrarlas. Los botines previos conservan el precio que tenían al generarse.

Tu mesa, sin conexión

Este HTML contiene toda la aplicación y su catálogo. No necesita cuentas, fuentes externas ni servicios de internet.

El guardado automático funciona en este navegador y dispositivo cuando permite almacenamiento local. Abrir otra copia, cambiar de navegador o borrar sus datos puede dejar el historial inaccesible. Exportá un respaldo para trasladarlo o conservarlo.

El respaldo incluye catálogo, exclusiones, parámetros, reglas de precios y su activación, resultados y listas marcadas como guardadas. La importación valida el archivo y pide confirmación antes de reemplazar datos.

Homebrew de precios del prototipo

Compatible con reglas de tipo «item» o «categoria», target, precioModo («fijo» o «multiplicador»), precioValor y nota. Una regla de ítem tiene prioridad sobre la de categoría. Se aplican a nuevas tiradas.

Decisiones para revisar

  • Limpiar pantalla oculta resultados previos; no borra el historial. «Ver historial completo» los recupera.
  • Ediciones de fichas base se conservan como notas homebrew separadas. Objetos propios siguen siendo editables.
  • El costo usa los precios homebrew activos; el valor base se conserva por separado.
  • Rarezas ambiguas quedan «por revisar», fuera del generador hasta clasificarlas. Las tablas D100 originales están integradas. Sigue pendiente completar y revisar todas las fichas del catálogo.

Guardar listas y limpiar historial

Todo resultado se conserva al recargar. «Guardar lista» lo protege de «Limpiar historial», que borra en una sola operación los resultados no marcados. «Limpiar pantalla» solo los oculta. Duplicar una lista crea una copia sin marcar como guardada.

Cómo se calcula

  • Bandas de nivel: 1–4, 5–10, 11–16 y 17–20. Riqueza base: 10–60, 60–400, 400–3000 y 3000–12000 PO.
  • Dificultad: ×0,5 / ×0,75 / ×1 / ×1,35 / ×1,75. Cofre ×1,2; enemigo ×0,4; otros ×1. En grupos se multiplica además por cantidad / 4.
  • Los pesos de rareza se normalizan entre las categorías que tienen objetos disponibles. Un peso cero excluye esa categoría.
  • La selección puede repetir objetos; se agrupan sus cantidades. Las gemas usan valores de ambientación del prototipo.
  • Artefactos: no hay ninguno precargado. Crealos en el catálogo y habilitalos expresamente.

Alcance de esta versión

Módulo de loot personal. El catálogo editable es su soporte; mercado, crafteo y encuentros siguen pendientes. La interfaz se adapta al celular; esta entrega es un HTML descargable, todavía no una app Android instalable.
