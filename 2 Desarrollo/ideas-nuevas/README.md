# Ideas nuevas — taller creativo de Romanance

**Creado:** 2026-10-11 · **Alcance:** exploración, fuera del 1 Canon oficial activo.

Este espacio permite crear directamente desde los archivos del proyecto: probar ideas, desarrollar personajes, escribir escenas o explorar mecánicas. Las propuestas pueden evolucionar con libertad antes de decidir cuáles incorporar.

No es una nueva categoría del 1 Canon oficial ni obliga a desarrollar contenido durante Fase 1. Es un espacio de trabajo para cuando el autor quiera explorar.

## Cómo usarlo

En este mismo chat alcanza con pedir, por ejemplo:

> «Exploremos en ideas nuevas una manifestación de Morvath mediante la Luz. Usá el 1 Canon oficial como base, proponé con libertad y guardalo como propuesta».

También se puede conversar sin guardar archivos. Un chat dedicado es opcional; estas instrucciones viven en el repositorio para que los chats que trabajen aquí puedan consultarlas.

El contenido no se incorpora automáticamente al canon. Cuando el autor aprueba una versión concreta, se coteja y traslada a su destino correspondiente, conservando la procedencia. Las variantes no aprobadas siguen como propuestas o descartes.
