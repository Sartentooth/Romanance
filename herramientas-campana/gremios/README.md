# Sistema de Gremios y Bastiones (mejorados)

**Versión de ficha:** 1.1 · **Fecha:** 2026-10-10 · **Estado:** EN DESARROLLO.

Bases v0.10 documental. El modelo combina función profesional y grupo aventurero propio, con excepciones: Sanadores de Romanance es exclusivamente profesional. Los aventureros usan encargos, rangos y padrinazgo; la afiliación profesional mantiene requisitos del oficio. Crecimiento institucional anual en tiempo de ficción, resolución narrativa y/o d20 opcional, aportes de PJ y mejoras. Bastiones y viviendas son una adaptación por desarrollar.
